# 📱 תיעוד אפליקציית אנדרואיד: FeedbackWithFragments

________________________________________
## 🧾 מידע כללי
*   **שם הפרויקט:** FeedbackWithFragments
*   **מחבר:** זאב פריימן (Zeev Fraiman)
*   **תאריך:** מאי 2024
*   **שפה:** Java
*   **סביבת פיתוח:** Android Studio
*   **גרסת אנדרואיד:** minSdk 28 / targetSdk 36
________________________________________
## 🎯 מטרת הפרויקט
•   **המשימה:** אספקת ממשק משתמש נוח למשלוח משוב בערוצי תקשורת שונים (SMS, אימייל, טלפון).
•   **חשיבות:** ריכוז שיטות התקשורת באפליקציה אחת מפשט את האינטראקציה של המשתמש עם התמיכה או המפתח.
•   **קהל יעד:** משתמשי מובייל הזקוקים לגישה מהירה לאפשרויות יצירת קשר.
________________________________________
## 📌 דרישות המערכת
### דרישות פונקציונליות
•   מעבר בין מסכי קלט ללא טעינה מחדש של ה-Activity.
•   בדיקה אוטומטית של זמינות הרשת וחסימת פונקציות לא זמינות.
•   הזנת טקסט ומספר טלפון עבור SMS.
### דרישות לא פונקציונליות
•   **ביצועים:** החלפת פרגמנטים מיידית.
•   **נוחות:** כפתורי שליטה אינטואיטיביים בחלק התחתון של המסך.
•   **אמינות:** מניעת ניסיונות שליחת נתונים כאשר אין חיבור לרשת.
________________________________________
## 🧠 ארכיטקטורה כללית
•   **גישה נבחרת:** MVC (Model-View-Controller).
•   **מדוע:** עבור פרויקט קטן, זה מאפשר הפרדה ברורה בין לוגיקת הניהול (Activity) לממשק (Fragments).
•   **רכיבים:**
    *   `MainActivity` — ה-Controller.
    *   `Fragments` — ה-Views.
    *   `BroadcastReceivers` — מאזינים לאירועי מערכת.
________________________________________
## 🧩 תיאור מחלקות
### 📌 מחלקה: MainActivity
*   **תפקיד:** מרכז ובקר ראשי.
*   **אחריות:** ניהול מחזור החיים של הפרגמנטים, רישום רסיברים של הרשת.
*   **מתודות עיקריות:**
    *   `onCreate()` — אתחול אלמנטים והגדרת מאזינים.
    *   `updateButtonsState()` — לוגיקה לבדיקת זמינות רשת סלולרית.

### 📌 מחלקה: SMSFragment / MailFragment / PhoneFragment
*   **תפקיד:** מודולים של הממשק.
*   **אחריות:** איסוף נתונים מהמשתמש.
