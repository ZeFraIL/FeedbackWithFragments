# תיאור מחלקה: PhoneFragment

## 1. מידע כללי
*   **שם המחלקה:** PhoneFragment
*   **סוג:** Fragment
*   **ייעוד:** מסך להזנת מספר טלפון.
*   **אינטראקציה:** אוסף את המספר ומעביר אותו ל-`MainActivity` דרך הפונקציה `receiveData`.

## 2. משתנים (שדות המחלקה)
| שם המשתנה | סוג | תפקיד |
| :--- | :--- | :--- |
| `etPhone` | EditText | שדה להזנת המספר |
| `bCallNumber` | Button | כפתור ה"חיוג" |

## 3. מתודות (פונקציות)
### מתודה: onCreateView()
*   **תיאור:** יוצרת את ממשק ההזנה. בעת לחיצה על הכפתור, הפרגמנט "פונה" לאקטיביטי שמחזיקה אותו (MainActivity) ומעביר לה את המספר שהמשתמש הזין.

## 6. אינטראקציה עם רכיבים אחרים
הפרגמנט הזה שולח מידע "למעלה":
1. קורא את הטקסט מהשדה.
2. מוצא את ה-`MainActivity`.
3. מפעיל את הפונקציה `receiveData(st1)` שנמצאת שם.

## 8. הסבר במילים פשוטות
**PhoneFragment** הוא כמו לוח מקשים של אינטרקום. אתם מקישים את מספר הדירה (מספר הטלפון), לוחצים על כפתור הקריאה, והסיגנל עובר למרכזיה הראשית (**MainActivity**), שהיא זו שמחליטה מה לעשות עם המידע הזה.
