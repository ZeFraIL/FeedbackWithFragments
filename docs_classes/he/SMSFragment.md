# תיאור מחלקה: SMSFragment

## 1. מידע כללי
*   **שם המחלקה:** SMSFragment
*   **סוג:** Fragment (רכיב ממשק)
*   **ייעוד:** מספק מסך משנה להזנת הודעת SMS ומספר טלפון.
*   **אינטראקציה:** פועל בתוך ה-MainActivity. הוא אוסף את מה שהמשתמש הקליד ומציג את זה כהודעה קופצת (Toast).

## 2. משתנים (שדות המחלקה)
| שם המשתנה | סוג | תפקיד |
| :--- | :--- | :--- |
| `etPhoneNumber` | EditText | שדה להזנת מספר הטלפון |
| `etSMStext` | EditText | שדה להזנת תוכן ההודעה |
| `bSendSMS` | Button | כפתור ה"שליחה" |

## 3. מתודות (פונקציות)
### מתודה: onCreateView()
*   **תיאור:** בונה את הממשק של הפרגמנט. היא מחברת בין הכפתורים לקוד ומגדירה שבעת לחיצה על כפתור השליחה, הטקסט מהשדות יישמר במשתנים ויוצג למשתמש.

## 4. מחזור חיים (Lifecycle)
*   **onCreateView():** השלב שבו המערכת "מציירת" את הפרגמנט על המסך ומכינה אותו לשימוש.

## 8. הסבר במילים פשוטות
**SMSFragment** הוא כמו טופס ריק שצריך למלא. יש בו מקום למספר ומקום להודעה. כפתור ה"שליחה" הוא כמו החותמת: הוא מאשר שסיימתם למלא את הטופס ומראה לכם מה כתבתם כדי לוודא שזה נכון.
