# Описание класса: PhoneFragment

## 1. Общая информация
*   **Имя класса:** PhoneFragment
*   **Тип:** Fragment (Кусочек экрана)
*   **Назначение:** Экран для ввода номера телефона.
*   **Взаимодействие:** Собирает номер телефона и передает его обратно в `MainActivity` через специальный метод `receiveData`.

## 2. Переменные (Поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `etPhone` | EditText | Поле для ввода телефона | `onCreateView` |
| `bCallNumber` | Button | Кнопка подтверждения | `onCreateView` |
| `st1` | String | Текст из поля ввода | `onClick` |

## 3. Методы класса
### Метод: onCreateView()
*   **Описание:** Создает интерфейс ввода. Внутри этого метода настроено событие: когда пользователь нажимает на кнопку, программа находит главную активность (`MainActivity`) и «отдает» ей введенный номер телефона.
*   **Особенность:** Здесь используется команда `(MainActivity) getActivity()`. Это способ фрагмента «постучаться» к своему родителю (активности).

## 4. Жизненный цикл
*   **onCreateView():** Инициализация: связываем кнопки в коде с кнопками на экране.

## 6. Взаимодействие с другими компонентами
Этот фрагмент не просто показывает данные, он передает их «наверх».
1. Считывает текст.
2. Ищет `MainActivity`.
3. Вызывает в ней метод `receiveData(st1)`.

## 8. Объяснение простыми словами
**PhoneFragment** — это как клавиатура домофона. Ты вводишь номер квартиры (телефон), нажимаешь «Вызов», и сигнал уходит в главный блок управления (MainActivity), который уже решает, что с этим делать дальше.
