# Описание класса: MainActivity

## 1. Общая информация
*   **Имя класса:** MainActivity
*   **Тип:** Activity (Экран приложения)
*   **Назначение:** Главный экран приложения. Он служит «командным центром», который переключает фрагменты (мини-экраны) и следит за состоянием интернета и мобильной связи.
*   **Взаимодействие:** Управляет фрагментами `SMSFragment`, `MailFragment` и `PhoneFragment`. Получает данные от фрагментов и выводит их на экран.

## 2. Переменные (Поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `bSms`, `bMail`, `bPhone` | Button | Кнопки управления | `initElements`, `onCreate` |
| `flFragments` | FrameLayout | Контейнер для отображения фрагментов | `onCreate` (транзакции) |
| `context` | Context | Ссылка на окружение приложения | `initElements`, `Toast` |
| `networkReceiver` | BroadcastReceiver | «Слушатель» изменений интернета | `onResume`, `onPause` |
| `phoneStateReceiver` | BroadcastReceiver | «Слушатель» изменений мобильной сети | `onResume`, `onPause` |

## 3. Методы класса
### Метод: onCreate()
*   **Тип:** protected
*   **Возвращаемое значение:** void
*   **Параметры:** `Bundle savedInstanceState` (сохраненное состояние)
*   **Что делает:** Вызывается при запуске приложения. Находит кнопки на экране, привязывает к ним действия (нажатия). При клике на кнопку «заменяет» текущий фрагмент на нужный.
*   **Когда вызывается:** Один раз при создании экрана.

### Метод: updateButtonsState()
*   **Тип:** private
*   **Возвращаемое значение:** void
*   **Что делает:** Проверяет, включена ли мобильная сеть. Если интернета/связи нет, кнопки SMS и Phone становятся серыми (неактивными).
*   **Когда вызывается:** При старте и при каждом изменении состояния сети.

## 4. Жизненный цикл (Activity)
*   **onCreate():** Инициализация: создаем интерфейс и кнопки.
*   **onResume():** Активация: «включаем» слушателей сети, чтобы приложение знало о состоянии связи.
*   **onPause():** Засыпание: «выключаем» слушателей, чтобы не тратить заряд батареи.

## 5. Взаимодействие с интерфейсом (UI)
*   Используется `findViewById` для связи Java-кода с XML-разметкой.
*   Обрабатываются нажатия (`setOnClickListener`) на три главные кнопки.

## 6. Общая логика
Класс работает как диспетчер. Когда вы нажимаете на кнопку "SMS", он командует системе: "Убери то, что было в центре экрана, и покажи там SMSFragment". Параллельно он всегда «держит ухо востро» (через Receiver), чтобы вовремя отключить кнопки, если пропадет связь.

## 8. Объяснение простыми словами
Представь, что **MainActivity** — это пульт от телевизора с кнопками. Телевизор один (экран телефона), но кнопка "SMS" включает канал про сообщения, а "Phone" — канал про звонки. Если кабель (сеть) выткнут, пульт просто не даст тебе переключиться на эти каналы.
