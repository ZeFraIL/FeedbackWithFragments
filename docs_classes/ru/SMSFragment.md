# Описание класса: SMSFragment

## 1. Общая информация
*   **Имя класса:** SMSFragment
*   **Тип:** Fragment (Кусочек экрана)
*   **Назначение:** Предоставляет интерфейс для ввода SMS-сообщения и номера телефона. Это «под-экран», который живет внутри MainActivity.
*   **Взаимодействие:** Работает внутри MainActivity. Собирает данные из текстовых полей и выводит их в виде всплывающего уведомления (Toast).

## 2. Переменные (Поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `etPhoneNumber` | EditText | Поле для ввода номера телефона | `onCreateView` |
| `etSMStext` | EditText | Поле для ввода текста сообщения | `onCreateView` |
| `bSendSMS` | Button | Кнопка «Отправить» | `onCreateView` |
| `st1` | String | Хранит текст сообщения | `onClick` |
| `st2` | String | Хранит номер телефона | `onClick` |

## 3. Методы класса
### Метод: onCreateView()
*   **Тип:** public
*   **Возвращаемое значение:** View (Созданный интерфейс)
*   **Параметры:** `LayoutInflater`, `ViewGroup`, `Bundle`
*   **Что делает:** Создает внешний вид фрагмента. Находит текстовые поля и кнопку. Устанавливает слушатель нажатия на кнопку «Отправить». При нажатии он считывает то, что написал пользователь, в переменные `st1` и `st2` и показывает сообщение на экране.
*   **Когда вызывается:** Когда MainActivity решает показать этот фрагмент пользователю.

## 4. Жизненный цикл (Fragment)
*   **onCreateView():** Главный метод для фрагмента. Здесь мы «надуваем» (inflate) разметку из XML-файла и превращаем её в живой объект в памяти.

## 5. Взаимодействие с интерфейсом (UI)
*   **EditText:** Используются для ввода данных пользователем.
*   **Button:** При нажатии срабатывает логика сбора данных.
*   **Toast:** Всплывающее окошко, которое показывает результат (введенный текст).

## 7. Общая логика
Это простой почтовый конверт. Пользователь пишет «Кому» и «Что», нажимает кнопку, и приложение показывает: «Я всё прочитало, вот твои данные».

## 8. Объяснение простыми словами
**SMSFragment** — это как бланк на почте. Сам по себе он ничего не делает, он просто лежит в папке (MainActivity). Когда ты его достаешь, ты можешь заполнить пустые поля. Кнопка «Отправить» — это как печать: она подтверждает, что ты закончил писать, и показывает тебе результат твоих трудов.
